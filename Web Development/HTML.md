# HTML

## What is HTML

- stands for **HyperText Markup Language**
- HTML is **not a programming language** - it just marks up a document
- Used to describe the structure of a document

## Example of HTML

```html
<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Gooner's Domain</title>
</head>

<body>
    <h1>Gooner's Domain</h1>
    <p>
        <!-- comment tintinadignadignadigniadpg-->
    </p>
</body>

</html>
```
