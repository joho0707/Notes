## Notes
- Goal of security program: provides assurance of availability, confidentiality, integrity (Security control)
- Management Control - management of computer security system + management of risk
- Operational Control - mechanisms primarily implemented + executed by people
- Technical Control - security on what the computer system executes
- Physical Control - ensure hardware is secure, i.e. doesn't malfunction, making back-up files
- Administrative Control - disciplinary rules and standards for employees, e.g. supervising
- Computational Control - monitoring use of system software
## Summary
- Security not just about limits for software, it's structure of management, employees, admin, etc. outside of software too
